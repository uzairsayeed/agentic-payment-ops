11. HTTP ERROR MODEL
    Main files:

    app/domain/payment.py
    → InvalidPaymentData
    → InvalidPaymentTransition

    app/application/payment_service.py
    → PaymentNotFoundError

    app/api/main.py
    → converts internal errors to HTTP

    Mapping:

    malformed request
    → 422

    invalid business data
    → 400

    payment missing
    → 404

    invalid transition
    → 409

    unexpected failure
    → 500

        ↓
